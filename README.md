FitWell is a fitness and health tracking mobile application designed to provide personalized workout routines, exercise tracking, account security, and progress monitoring.

The application features a dark, modern interface with responsive layouts designed for mobile phones, foldables, and tablets.

## Features

### Authentication and Account Security

- **User Onboarding:** Welcome screen with swipe-up navigation and social authentication options.
- **Sign Up and Login:** Form validation, password visibility controls, and session handling.
- **OTP Verification:** Four-digit security codes with native Android system notifications.
- **Password Recovery:** Account password reset and update flow.

### Fitness and Progress Tracking

- **Workout Programs:** Training categories for strength, cardio, and endurance.
- **Exercise Library:** Exercise instructions, target muscle groups, and movement demonstrations.
- **Health Metrics:** BMI calculator and progress tracking over time.
